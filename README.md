# AI/ML Labs

A collection of implementations, experiments, and projects covering Artificial Intelligence, Machine Learning, Generative AI, and AI-powered applications.

## Overview

A workspace for exploring AI/ML concepts, experimenting with tools and frameworks, implementing algorithms, and building practical applications.

## Topics

- **Artificial Intelligence:** Core concepts, search algorithms, and intelligent systems.
- **Machine Learning:** Supervised learning, unsupervised learning, model training, and evaluation.
- **Deep Learning:** Neural networks and deep learning architectures.
- **Data Science:** Data preprocessing, feature engineering, and data visualization.
- **Generative AI:** Large Language Models (LLMs), prompt engineering, and inference.
- **Embeddings and Vector Search:** Text vectorization, semantic search, similarity measures, and retrieval.
- **Vector Databases:** ChromaDB, indexing, storage, and retrieval of vector embeddings.
- **AI Agents:** Tool calling, agent workflows, planning, and autonomous task execution.
- **Retrieval-Augmented Generation (RAG):** Document processing, retrieval pipelines, and context-aware generation.
- **AI Application Development:** Integrating models, APIs, databases, and tools into working applications.

## Objectives

- Understand AI/ML concepts through practical implementations.
- Explore libraries, frameworks, and emerging AI technologies.
- Experiment with embeddings, vector search, LLMs, and AI agents.
